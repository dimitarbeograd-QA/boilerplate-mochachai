# Contributing

## Как да допринесеш
1. `npm install`
2. Довърши placeholder тестовете в `tests/` (виж статус в [`qa-docs/TEST_CASES.md`](qa-docs/TEST_CASES.md)).
3. `npm test` — увери се, че suite-ът минава зелено.
4. За референция при довършване, виж решената версия в [`QA` repo](https://github.com/dimitarbeograd-QA/QA).
